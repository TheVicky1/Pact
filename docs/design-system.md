# PACT design system

PACT uses dark graphite, warm ivory, restrained amber, and quiet cool atmospheric light. Glass signals hierarchy and focus, never a blanket treatment.

- Canvas `#090a0c`; text `#f5f1e8`; muted `#aaa69f`; accent `#d3a866`.
- Surfaces use translucent white at 2.5–9% with a 1px white border at 7–11%.
- The current V0 uses the system sans stack for fast, reliable rendering; typography can move to a bundled brand font once an offline asset is selected.
- Navigation uses a quiet 86px desktop rail and a fixed four-item mobile dock; the mobile experience is a distinct touch-first layout, not a compressed rail.
- Use 12px utility controls, 22–28px content cards, and rounded pills only for focused actions.
- Empty states carry a calm action and explanatory copy; they never imitate unavailable financial, productivity, or integration data.
- Motion is 150–220ms and respects reduced-motion preferences.
- All controls are semantic, keyboard reachable, visibly focused, and retain readable contrast.
