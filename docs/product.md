# PACT V0 product scope

PACT is a personal accountability and finance operating system. Its loop is plan, commit, execute, measure, learn, improve. V0 prioritizes a dependable daily loop rather than broad dashboards.

Tasks are commitments; deadlines make them accountable; hidden consequences support recovery after a miss; spending data supports financial discipline. PACT is direct but never shaming.

## Delivery phases

1. Foundation, design system, and secure data boundary.
2. Authentication and progressive onboarding.
3. Commitments, completion, deadline evaluation, and consequences.
4. Expenses, categories, budgets, and daily calculations.
5. Today dashboard, daily sheet, score, and transparent insights.
6. Analytics, responsive polish, notifications, and one validated developer integration.

Integrations are optional; absent integrations never create empty dashboard clutter. No production page invents user metrics.
